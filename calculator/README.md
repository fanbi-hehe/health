# 计算器（小明计算器风格）

独立的 Android 计算器 App 模块，UI 参照“小明计算器”的极简风格：

- 深色显示区：顶部齿轮进入设置，显示区上方保留最近 3 条历史，下方为当前表达式与实时结果
- 经典 4 列键盘：`C ÷ × ⌫` / `7 8 9 −` / `4 5 6 +` / `1 2 3` / `0 .`，等号占右侧两行
- 绿色功能键/运算符键 + 灰色数字键，圆角矩形按钮
- 设置页内置 8 套按键配色（薄荷绿、水晶蓝、香槟金等，默认薄荷绿）
- 历史记录：底部面板展示完整表达式与结果，支持点击复用结果、单条删除、一键清空；历史通过 DataStore 本地持久化（最多 200 条）
- 计算逻辑：经典即时计算（按下运算符即结算），支持连续运算、负数开头（先按 `−`）、小数点、退格、除以 0 错误提示；结果最多 12 位有效数字

## 构建

```bash
./gradlew :calculator:assembleDebug
```

APK 输出：`calculator/build/outputs/apk/debug/calculator-debug.apk`

## 测试

```bash
./gradlew :calculator:testDebugUnitTest
```
